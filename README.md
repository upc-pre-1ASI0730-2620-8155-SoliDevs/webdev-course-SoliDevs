# 🌐 Fundamentos de Desarrollo Web

Sean bienvenidos al curso de Fundamentos de Desarrollo Web!!!

En este curso aprenderás los fundamentos de HTML y CSS de forma sencilla y amigable. Está diseñado especialmente para estudiantes de secundaria sin experiencia previa en programación. A través de videos con explicaciones paso a paso, te guiaremos hasta que logres construir y programar tu propia página web personal. ¡Disfruta del curso!

---

## 💡 Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS.

> ⚠️ **¡No requiere instalaciones ni configuraciones complejas!** Solo abre tu navegador web y disfruta del curso.

*   **⏱️ Duración total**: ~60 minutos
*   **👥 Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación.
*   **🎯 Prerrequisitos**: Ninguno
*   **💻 Herramientas necesarias**: ¡Solo tu navegador web! (Chrome, Firefox, Safari, Edge)
*   **📂 Repositorio de código fuente**: [https://shorturl.at/3jZah](https://github.com/upc-pre-1ASI0730-2620-8155-SoliDevs/webdev-course-SoliDevs.git)


## 📚 Secuencia de Lecciones

### 🎬 Lección 1: ¿Qué es el desarrollo web y cómo funciona internet? (10 min)
*   **Descripción**: En esta lección se brindará una explicación sencilla de qué es un sitio web y cómo viaja la información desde un servidor hasta el navegador.
*   **Enlace**: [Ver la lección]()
*   **Consejos clave**: Sitios web = Contenido (HTML) + Estilo (CSS).
*   **Práctica**: [Open CodePen]()

### 🧱 Lección 2: Tus primeros bloques de construcción: Estructura HTML (10 min)
*   **Descripción**: En esta lección, descubriremos la estructura HTML inicial que toda página web posee, y aprenderemos para qué sirven sus herramientas: las etiquetas, el contenido y los atributos.
*   **Enlace**: [Ver la lección]()
*   **Consejos clave**: Al abrir una etiqueta HTML, recuerda siempre cerrarla.
*   **Práctica**: [Clic para programar en CodePen]()

### 🖼️ Lección 3: Dándole contenido a la página: Textos, Imágenes y Enlaces (12 min)
*   **Descripción**: En esta lección se agregarán listas, imágenes y enlaces para que tu página sea interactiva.
*   **Enlace**: [Ver la lección]()
*   **Consejos clave**: Usa las etiquetas `<ul>`, `<img>`, `<a>`.
*   **Práctica**: [Clic para programar en CodePen]()

### 🎨 Lección 4: Introducción a CSS: ¡Dándole color y estilo! (10 min)
*   **Descripción**: En esta lección aprenderas a darle estilo a una página web utilizando CSS. Cambia colores, fuentes y personaliza distintos elementos de tu página.
*   **Enlace**: [Ver la lección]()
*   **Consejos clave**: CSS se encarga de la apariencia. Utiliza selectores y propiedades como `background-color`, `font-family` y `color`.
*   **Práctica**: [Clic para crear estilos en Codepen]()

### 📐 Lección 5: Diseño y Bordes (12 min)
*   **Descripción**: En esta lección se dará una explicación sencilla y práctica sobre cómo darle estructura y forma a nuestra página con CSS.
*   **Enlace**: [Ver la lección]()
*   **Consejos clave**: Usar márgenes y espaciados para que la página se vea ordenada, y aplicar bordes redondeados.
*   **Proyecto Final**: [Clic para programar]()

### 🛠️ Lección 6: Errores comunes y consejos (10 min)
*   **Descripción**: En esta lección nos centraremos en corregir errores comunes de principantes y aplicar buenas prácticas para que nuestro código sea más entendible.
*   **Enlace**: [Ver Lección]()
*   **Consejos Clave**: Revisa que los atributos y rutas estén correctamente escritos, y aplica indentación para exponer una jerarquía entre los elementos.
*   **Práctica**: [Clic para programar]()

### 🚀 Lección 7: Creación final de la página web (15 min)
* **Descripción**: En esta lección se aplicará los conceptos aprendidos de HTML y CSS creando una tarjeta web sencilla sobre un videojuego. Utiliza títulos, imágenes, párrafos, enlaces y estilos para personalizar tu página.
* **Enlace**: [Ver la lección]()
* **Consejos clave**: HTML define la estructura de la página y CSS mejora su apariencia. Utiliza etiquetas como `h1`, `p`, `img` y propiedades como `background-color`, `color` y `border-radius`.
* **Práctica**: [Crear una tarjeta web en CodePen]()
